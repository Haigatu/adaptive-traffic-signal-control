Результаты

Меньшая задержка лучше. Дообучение не даёт универсального выигрыша: при малой нагрузке результат ухудшается; лучшая базовая политика остаётся быстрее на каждом из трёх уровней нагрузки в этом тесте.

Нагрузка 0.40: исходный D3QN 105.3 с → дообученный 112.6 с (+6.9%). Только ограничение: 76.6 с. Лучший из двух базовых методов — Max Pressure: 27.7 с.

Нагрузка 0.70: исходный D3QN 218.2 с → дообученный 120.4 с (-44.8%). Только ограничение: 156.7 с. Лучший из двух базовых методов — Webster: 104.8 с.

Нагрузка 0.95: исходный D3QN 765.3 с → дообученный 680.3 с (-11.1%). Только ограничение: 868.5 с. Лучший из двух базовых методов — Webster: 626.1 с.

Что изменилось в обучении

Исходный efficiency-only D3QN с прогнозом перенесён с 52 на 56 входов. Новые столбцы весов инициализированы нулями; остальные веса сохранены. Оптимизатор и replay buffer для нового этапа созданы заново. Затем выполнены 30 новых эпизодов при нагрузке 0.7, seed обучения 0, дорожные seeds 10000–10029. Epsilon снижен с 0.30 до 0.05. Остались Adam 1e−4, batch 32, target sync 500 и discount с учётом длительности действия. Ограничение не заменяет модель: среди допустимых действий фазу выбирает D3QN.

Сохранены финальные обученные веса, выбранный validation-checkpoint, четыре промежуточных кандидата и resume.pt: optimizer, target network, replay buffer и RNG. Возобновление возможно между завершёнными эпизодами. Во время незавершённого эпизода процесс начнёт этот эпизод заново.

Границы вывода

Это пилот на одном синтетическом перекрёстке и одном seed обучения. Четыре seeds тестового спроса недостаточны для вывода об общей статистической устойчивости. Ограничение максимального ожидания не является доказательством безопасности движения. Новое обучение оптимизирует задержку (w=1); TTC только измеряется. Нулевые столкновения в выполненных прогонах не доказывают безопасность.

Задержка остаётся интегральным прокси потери скорости и ожидания вставки в сеть, делённым на запрошенный спрос. Это не полное время поездки минус free-flow для завершившейся когорты. При нагрузке 0.95 возможна перегрузка; короткое ожидание зелёного само по себе не устраняет транспортный затор. Все ограничения геометрии, датчиков и переноса данных из первоначального отчёта сохраняются.
